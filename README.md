## 🏆 Proyectos y Logros Técnicos Destacados

Aquí algunos ejemplos de cómo aplico la tecnología para resolver problemas reales (basados en mi experiencia profesional):

### 🔄 Automatización y ETL
* **Pipeline de Limpieza de Datos con Python:** Desarrollé scripts para automatizar tareas de Extracción, Transformación y Carga (ETL), logrando una reducción significativa en los tiempos de limpieza de datos y eliminando errores manuales en reportes humanitarios.
* **Gestión de APIs:** Modelado de formularios conectados vía API a Excel/Power BI para salvaguardar la información original y facilitar el análisis en tiempo real.

### 📊 Visualización y Business Intelligence
* **Dashboard Financiero (Control de Presupuesto):** Creé tableros en Power BI para controlar la ejecución presupuestal en proyectos financiados en dólares, permitiendo prever ajustes por fluctuación de la tasa de cambio.
* **Análisis de Cadena de Suministro:** Implementé gráficos de cajas y bigotes (boxplots) para identificar anomalías (outliers) en los precios de proveedores, facilitando auditorías rápidas.
* **Estudios de Viabilidad:** Diseñé visualizaciones para evaluar la apertura de nuevas oficinas operativas basadas en datos de encuestas de sondeo.

### 📱 Desarrollo de Aplicaciones (Low-Code)
* **Sistema de Mesa de Ayuda (Power Apps):** Desarrollé una aplicación para centralizar y gestionar solicitudes de ajustes de información, organizando el flujo de trabajo del equipo de gestión de datos.
